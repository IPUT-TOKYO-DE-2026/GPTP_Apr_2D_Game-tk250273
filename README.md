# PingPong Rogue

## ゲームの内容
プレイヤーを操作し、飛んでくるボールを跳ね返し、ゴールにシュートしよう
ボールは跳ね返るたびにスピードが上昇し、スコアが10増える
ゴールにシュートするとスコアが100増える
スコアが一定の値を超えると
-　ボールのスピードを落とす
-　ボールの大きさが変わる
-　ボールを一つ追加する
という選択肢が出てくる、適切に選んでハイスコアを目指そう


（プレイ中のスクリーンショットをドラッグ＆ドロップして追加する）

## 操作説明
- Wキー：プレイヤーを上に動かす
- Sキー：プレイヤーを下に動かす
- クリック：選択肢を選択
